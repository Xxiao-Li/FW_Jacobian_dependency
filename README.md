# Structural dependencies

This repository contains the code and data used in the paper "Structural dependencies in trophic interactions promote stability in natural food webs".

In this study, we examine these structural dependencies in food webs and ask how they influence local stability as represented by the Jacobian matrix. Specifically, we distinguish three forms of structural dependency among Jacobian elements: consumer–resource interaction dependency, shared biomass dependency, and shared consumer conversion efficiency dependency. We then investigate how each of these dependencies affects food-web stability.
